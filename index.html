SD Job Agent

A personal job-search assistant for Project Manager roles.

SD Job Agent runs once each morning for its operator, Sudhakara Reddy Gorla:

  1. Find: collects fresh remote and hybrid Project Manager postings.
  2. Score: rates how well each posting fits the operator's resume and keeps only strong matches.
  3. Tailor: prepares an ATS-friendly resume for each match by reordering and rewording the operator's real experience. It never invents anything.
  4. Save: stores each resume as a Google Doc and a PDF in the operator's Google Drive, one folder per job.
  5. Track: adds each job to a Google Sheet so the operator can track applications, interviews, and offers.

The app never applies to jobs itself. The operator reviews every resume and applies personally.

Google data

SD Job Agent uses Google Drive, Docs, and Sheets only to create and update its own resume files and tracker in the operator's Drive. See the Privacy Policy for details.
