SD Job Agent

Privacy Policy

Effective date: October 19, 2026

SD Job Agent ("the app") is a personal automation tool operated by Sudhakara Reddy Gorla for his own job search. It finds Project Manager job postings, prepares a tailored resume for each suitable posting, and records each one in a tracking spreadsheet. The app is not offered to the public, and its only user is its operator.

Google user data the app accesses

When the operator signs in with Google, the app requests these permissions:

  • Google Drive (https://www.googleapis.com/auth/drive): to create a "Job Applications" folder, create a dated folder and a per-job folder inside it, save resume files, and move superseded resume files to the trash.
  • Google Docs (https://www.googleapis.com/auth/documents): to create the tailored resume as a Google Doc and export it as a PDF.
  • Google Sheets (https://www.googleapis.com/auth/spreadsheets): to create and update the "Job Application Tracker" spreadsheet.
  • Basic profile and email (openid, userinfo.email, userinfo.profile): to identify which Google account is signed in.

How the data is used

  • The app only creates, reads, updates, and trashes files it manages inside the operator's own Google Drive: resume documents and PDFs, the folders that hold them, and the tracker spreadsheet.
  • The app does not read, analyze, or modify any other files in the operator's Drive.
  • Google user data is used only to provide these features to the operator.

Sharing and transfer

  • Google user data is never sold, rented, or shared with third parties.
  • It is not used for advertising.
  • It is not used to train artificial intelligence or machine learning models.
  • Resume text based on the operator's own resume is sent to an AI model provider (OpenRouter) to tailor it to a job posting. No Google user data, such as Drive file contents or account information, is sent to that provider.

Storage and security

  • Google sign-in credentials (OAuth tokens) are stored encrypted on the operator's own computer.
  • For scheduled runs, they are also stored as an encrypted secret in the operator's private Modal.com account.
  • Resume documents and the tracker remain in the operator's Google Drive.
  • The app keeps no separate database of Google user data.

Retention and deletion

Files created by the app stay in the operator's Google Drive until the operator deletes them. To revoke the app's access at any time, visit myaccount.google.com/permissions and remove "SD Job Agent". Revoking access stops the app from reaching any Google data.

Limited Use disclosure

SD Job Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
